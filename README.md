# ChainBreaker AI 🛡️⛓️

### BREAK THE CHAIN OF MISINFORMATION IN REAL-TIME

ChainBreaker AI is a cutting-edge, production-ready misinformation defense system designed to identify and halt the spread of fake news, viral claims, and manipulated content before they reach the masses.

Built with a **billion-dollar startup aesthetic**, this project features a stunning, futuristic frontend and a robust, modular backend.

---

## ✨ Features

*   **🛡️ Real-Time Detection**: Proactively identify suspicious claims as they appear.
*   **🧠 Neural Fact-Check Engine**: Advanced AI models verify content against reliable global databases.
*   **🎙️ Multi-modal Analysis**: Seamlessly handles both text and audio voice note analysis.
*   **📊 Virality Prediction**: Proprietary scoring algorithm to assess the potential risk of a claim.
*   **📉 Impact Dashboard**: Visual summary of misinformation detected and "chains broken."
*   **🌐 Privacy First**: End-to-end encrypted analysis ensures your data remains secure and private.

## 🚀 Tech Stack

### **Frontend**
*   **React + Vite**: High-performance, modern development environment.
*   **Tailwind CSS**: Premium, dark-themed UI system with glassmorphism and neon accents.
*   **Framer Motion**: Fluid, high-end micro-interactions and transitions.

### **Backend**
*   **FastAPI**: Blazing fast, asynchronous Python web framework.
*   **Whisper AI**: Industry-leading transcription for audio notes.
*   **Custom LLM Chain**: Deterministic and refined analysis pipeline for high accuracy.

## 🛠️ Installation & Setup

### **Backend Setup**
1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Sekhar-Harshitha/Chainbreaker-AI.git
    cd Chainbreaker-AI
    ```
2.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
3.  **Environment Variables**:
    Create a `.env` file in the root and add your configuration (Twilio, OpenAI, etc.).
4.  **Run the Server**:
    ```bash
    uvicorn app.main:app --reload
    ```

### **Frontend Setup**
1.  **Navigate to Frontend**:
    ```bash
    cd frontend
    ```
2.  **Install Packages**:
    ```bash
    npm install
    ```
3.  **Start Development Server**:
    ```bash
    npm run dev
    ```
